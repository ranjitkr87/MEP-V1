# 🏗️ MEP Contracting Company Website Template

A modern, responsive MEP contracting company website template built with **React + Vite**.

Designed for **MEP contractors, HVAC contractors, electrical contractors, plumbing contractors, mechanical contractors, building services companies, engineering firms, and construction companies** operating across commercial, residential, industrial, and infrastructure projects.

The template provides a polished professional foundation that can be quickly adapted for different MEP businesses by updating content, projects, images, branding, services, and contact details.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

```bash
cd mep-contracting-company
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The website will be available at the local development URL provided by Vite.

## 🎯 Template Philosophy

This project follows a **productized website** approach.

Instead of creating a completely custom website for every MEP contractor, the underlying design and development system remains standardized while customer-specific content, branding, services, projects, and company information are customized.

This allows websites to be:

- Faster to launch
- Easier to maintain
- More affordable
- Consistent in quality
- Easier to deploy
- Reusable across multiple MEP companies
- Easier to scale across different markets

The same foundation can be adapted for companies operating in **India, UAE, Saudi Arabia, Qatar, Oman, Bahrain, Kuwait, and other international markets**.

## 🔒 Security

This is primarily a frontend corporate website and does not require sensitive customer or project information.

Do not store:

- Customer credentials
- Authentication credentials
- API secrets
- Private keys
- Confidential project documents
- Sensitive employee information
- Other confidential business information

in the frontend source code or public repository.

Public-facing project information should only be published with the customer's approval.
